# University Management System

A console-based University Management System developed in **C++** implementing Object-Oriented Programming (OOP) principles and persistent file handling.

## 🚀 Features
- **Add Student Record:** Register new students with Roll Number, Name, Subject, and Address.
- **Search Record:** Instantly look up student details using their unique Roll Number.
- **Update Record:** Modify existing student records seamlessly.
- **Display All Records:** View a comprehensive list of all registered students in the database.
- **File Handling:** Persistent data storage using text files (`students.txt`) so data is never lost on exit.

## 🛠️ Technologies Used
- **Language:** C++
- **Concepts:** Object-Oriented Programming (OOP), File I/O (`fstream`), Vectors, Standard Template Library (STL)

## 💻 How to Run
1. Clone or download the repository.
2. Open the `UniversityManagementSystem.cpp` file in any C++ IDE (like Dev-C++, Code::Blocks, or VS Code).
3. Compile and run the program.
